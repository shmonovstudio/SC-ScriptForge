# Manrope

Unmodified static TTF files from the Manrope project, distributed under SIL Open Font License 1.1. The copyright notice and full license are in OFL.txt and published with the application in Licenses/Manrope-OFL.txt.

- Repository: https://github.com/googlefonts/manrope
- Pinned revision: 468c0dbe38efa331b80bfe9448256abe27be44c3
- Source directory: fonts/ttf/
- Files: manrope-regular.ttf, manrope-medium.ttf, manrope-semibold.ttf, manrope-bold.ttf

All four static weights are embedded. Manrope is used for headings, section titles, branding and navigation; Onest Regular/Medium is used for interface copy and inputs; JetBrains Mono is used for code. Installation into Windows is not required. Assembly-qualified asset URIs also resolve in the offscreen verification host.

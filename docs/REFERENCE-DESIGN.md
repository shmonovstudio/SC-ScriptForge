# Интерфейс по референсам

Обновлены общая оболочка, каталог, избранное, история запусков, ИИ-помощник и настройки. Дашборд — отдельный раздел в той же бело-бирюзовой палитре. Приложение остаётся на Avalonia; библиотека и существующий механизм выполнения PowerShell сохранены.

В каталоге есть постоянная панель выбранного скрипта, сведения, просмотр исходного кода и запуск через проверку параметров. История поддерживает поиск, фильтры, страницы по восемь записей и экспорт. Новые сценарии сохраняются в `automation.json` рядом с данными библиотеки.

Расписание сценариев напоминает о запуске, пока приложение открыто. Выполнение каждого шага подтверждается в существующем окне запуска. Следующий шаг открывается после успешного завершения и закрытия предыдущего окна. Это не фоновый планировщик Windows. Старые консольные логи не создаются: история показывает только реально сохранённые результаты.

Сборка: `dist/SC.ScriptForge.exe`. Запуск через `RUN.cmd` также использует обновлённую сборку. Пользовательская папка `dist/Data` при публикации не перезаписывалась.

## Проверка

- Release build: успешно, без ошибок компиляции.
- Проверка интерфейса без системного окна: 26 проверок, 0 ошибок.
- Проверка в настоящем окне Windows: 30 проверок, 0 ошибок.
- Контракты ИИ и интеграция интерфейса: 20 проверок, 0 ошибок.
- Проверены шесть основных экранов при 1370×990 и 960×640, светлая и тёмная темы, выбор скрипта, отсутствие устаревшей цели запуска после поиска, исходный код, избранное, сохранение шагов сценария и системные кнопки окна.
- Полный интеграционный тест PowerShell ограничен песочницей: Windows PowerShell 5.1 не получил доступ к реестру при `Get-ExecutionPolicy`. Политики выполнения не изменялись.
- При публикации NuGet не смог получить сетевой список уязвимостей (NU1900). Публикация завершилась успешно с локально доступными пакетами.

# SC ScriptForge 1.2 — шапка и библиотека

## Исправление наложения

Скриншот пользователя показал дефект, который не был виден в headless-проверке 1.1: при расширении клиентской области Avalonia 12 выводила собственный заголовок поверх логотипа. Глобальный шаблон Button также менял оформление кнопок окна.

Оставлен `WindowDecorations.Full`. В шаблоне оформления скрыт только дополнительный TextBlock заголовка и лишняя кнопка fullscreen. Для трёх стандартных кнопок задан отдельный компактный шаблон; сохранены штатные роли CloseButton, MinimizeButton и MaximizeButton. Поиск и кнопки приложения имеют роль User, свободные области шапки — TitleBar. Ручной BeginMoveDrag удалён, чтобы не дублировать системную обработку. Область темы отделена от кнопок окна зарезервированным отступом.

Основание: [изменения оформления в Avalonia 12](https://docs.avaloniaui.net/docs/avalonia12-breaking-changes#window-decoration-changes), [официальный шаблон установленной версии 12.1.4](https://github.com/AvaloniaUI/Avalonia/blob/12.1.4/src/Avalonia.Themes.Fluent/Controls/WindowDrawnDecorations.xaml). Обновление зависимостей для исправления не потребовалось.

## Рабочий сценарий библиотеки

1. Найти скрипт по названию, тегам или коду; при необходимости выбрать категорию и статус.
2. Выбрать строку каталога и проверить исходник справа.
3. Открыть «Настроить запуск», заполнить параметры и подтвердить выполнение в форме.
4. При необходимости перейти к редактору, заметкам, истории или дополнительным действиям.

Логотип показан один раз. В списке — название, короткое описание и метаданные; в просмотре — имя файла и его содержимое. Счётчик результатов остался в одном месте. Убрана высокая пустая карточка с вертикальной колонкой кнопок. Запуск и редактор закреплены снизу области просмотра; версии, сведения, синтаксис, профиль, копия, экспорт и корзина доступны в меню «…» и по правой кнопке строки.

Дизайн использует спокойные поверхности и тонкие разделители, сдержанный мятный акцент Shmonov Studio, оригинальный вектор SC и встроенные шрифты. Панели изменяют ширину через GridSplitter; поиск и фильтры доступны с клавиатуры и имеют имена для автоматизации. Нативный ListBox сохраняет виртуализацию и выбор с клавиатуры. Заметки и история показаны во вкладках, с отдельными объяснениями пустых состояний.

Предпросмотр читает файл асинхронно, отменяет чтение при уходе с экрана и ограничивает содержимое 400 строками / 65 536 символами. Подсветка — локальное визуальное выделение токенов с ограничением времени regex; это не синтаксическая проверка PowerShell. Номера строк не входят в выделяемый код. Копируется точный текст показанного исходника; при ограничении кнопка называется «Копировать фрагмент». Полный файл остаётся доступен в редакторе. Предпросмотр не вызывает PowerShell и не выполняет код.

Короткие эффекты появления, отклик кнопок и reduced motion сохранены. Переключение вкладок занимает 160 мс. Поиск в избранном не переводит пользователя в общую библиотеку. Сброс синхронизирует запрос, категорию и статус. Изменение избранного сохраняет выбранный скрипт. Пустой результат очищает прежнюю цель запуска.

## Проверка

Release: 0 предупреждений, 0 ошибок. `--ui-only`: 43 PASS, 0 FAIL. `--native-ui`: 9 PASS, 0 FAIL.

Проверены: 9 разделов, обе темы, 960×640, масштаб 150%, код с кириллицей, выделение текста через цветовые фрагменты, смена выбора, фильтрация и сброс, сохранение избранного, пустой результат, ограничение большого файла, перетаскивание разделителя, форма до выполнения, доступность дополнительных команд и работа reduced motion.

Отдельный прогон использует настоящий Win32 backend. Проверены скрытый дополнительный заголовок, три кнопки 44×38 DIP, отсутствие наложения переключателя темы, единственное выделение строки, интерактивная роль поиска и действия сворачивания/разворачивания/восстановления. Изображения получены RenderTargetBitmap из визуального дерева настоящего окна, включая оформление Avalonia. Это не снимки экрана Windows; системные тени и Snap flyout ими не проверяются. Физические мониторы, Snap и системные сочетания остаются предметом ручной проверки.

Команды:

```powershell
.\.tools\dotnet\dotnet.exe build Tests/SC.ScriptForge.Checks.csproj -c Release --no-restore -m:1 -p:UseSharedCompilation=false
.\.tools\dotnet\dotnet.exe Tests/bin/Release/net10.0-windows/SC.ScriptForge.Checks.dll --ui-only
.\.tools\dotnet\dotnet.exe Tests/bin/Release/net10.0-windows/SC.ScriptForge.Checks.dll --native-ui
```

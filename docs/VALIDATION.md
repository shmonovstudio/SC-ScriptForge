# Автоматические проверки

Проверки выполняются на Windows через [GitHub Actions](https://github.com/shmonovstudio/SC-ScriptForge/actions). Workflow описан в `.github/workflows/ci.yml`.

## Что проверяется

- Состав исходников: отсутствие исключённых файлов и типовых секретов, наличие всех штатных скриптов и метаданных.
- Восстановление закреплённых NuGet-зависимостей и Release-сборка .NET 10.
- PowerShell: синтаксис, параметры, отчёты, обработка ошибок, отмена, тайм-ауты и изоляция процессов.
- Библиотека: метаданные, версии, корзина, обновление штатных сценариев без перезаписи пользовательских изменений.
- Avalonia: представления, таблицы и карточки результатов, размеры окон, доступность элементов и закрытие окон запуска.
- SC AI без скачивания модели: контекст, просмотр и применение предложений, сообщения об отсутствии движка и модели.
- Загрузчик ИИ с локальным HTTP-сервером: докачивание, отмена, Range, контроль SHA256 и защита существующих файлов.
- Автономная публикация Windows x64.

## Локальный запуск

Из корня проекта в PowerShell 7:

~~~powershell
pwsh -NoProfile -File .\Tools\Prepare-GitHub.ps1
pwsh -NoProfile -File .\Tools\Test-Windows.ps1

# После сборки тестового проекта:
dotnet .\Tests\bin\Release\net10.0-windows\SC.ScriptForge.Checks.dll --ai-only
dotnet .\Tests\bin\Release\net10.0-windows\SC.ScriptForge.Checks.dll --ai-download-only
~~~

## Границы проверки

Обычный CI не скачивает большие модели и не проверяет качество реального вывода ИИ. Производительность, Windows 10, ARM64, несколько физических GPU, системные диалоги, перенос между мониторами и работа с реальной инфраструктурой AD требуют отдельных проверок. Результат последнего запуска и журналы доступны в GitHub Actions; локальные отчёты и данные компьютера в исходники не включены.

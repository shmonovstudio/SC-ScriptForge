# SC ScriptForge

Windows-приложение Shmonov Studio для библиотеки PowerShell-скриптов, запуска проверок, просмотра результатов и работы с локальным ИИ.

Версия **1.6.1** · **C# / .NET 10 / Avalonia** · **Windows x64**.

## Возможности

- Библиотека, поиск, категории, избранное, редактор, версии и корзина.
- 22 встроенных сценария: Active Directory, Windows, сеть, файлы, сертификаты и серверы.
- Параметры PowerShell, история запусков, таблицы и экспорт отчётов.
- Инвентаризация компьютера и русский/английский интерфейс библиотеки.
- SC AI: создание, объяснение и проверка скриптов; локальные модели или OpenAI-совместимый сервер.

## Сборка из исходников

Требуются Windows, [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) и PowerShell 7 (`pwsh`) для команд подготовки и публикации. Windows PowerShell 5.1 используется частью встроенных проверок.

В корне проекта выполните:

```powershell
dotnet restore SC.ScriptForge.csproj --locked-mode
dotnet build SC.ScriptForge.csproj -c Release --no-restore
pwsh -NoProfile -File .\Tools\Publish-Windows.ps1
.\dist\SC.ScriptForge.exe
```

`BUILD-AND-RUN.cmd` также собирает и запускает приложение. `RUN.cmd` запускает существующую сборку или создаёт её, если она отсутствует. Каталог `dist` создаётся локально и не хранится в Git. Публикация по умолчанию создаёт автономную сборку win-x64.

## Проверки

```powershell
pwsh -NoProfile -File .\Tools\Prepare-GitHub.ps1
pwsh -NoProfile -File .\Tools\Test-Windows.ps1
```

В проекте собственный исполняемый набор проверок; запускайте `Test-Windows.ps1`, а не только `dotnet test`. GitHub Actions проверяет состав репозитория, сборку, тесты и публикацию Windows. Проверки с реальной моделью ИИ запускаются отдельно и не требуют загрузки модели в обычном CI.

## Данные и локальный ИИ

Рабочие данные хранятся рядом с EXE в `Data`; при отсутствии доступа на запись используется `%LOCALAPPDATA%\Shmonov Studio\SC ScriptForge\Data`. Сохраняйте эту папку при обновлении.

В Git включены только 22 штатных скрипта и их метаданные из [списка поставки](Build/BundledScripts.props). Пользовательские скрипты, история, профили, настройки ИИ, отчёты и резервные копии исключены. Для добавления штатного скрипта обновите и список поставки, и исключения в `.gitignore`.

**Исходный код SC AI включён в проект.** Модели ИИ и движок llama.cpp не поставляются в репозитории.

Для локальной работы скачайте их через **SC AI → Локальный ИИ** — встроенный установщик выполнит загрузку и настройку. Интернет требуется для скачивания; дальнейшая работа локальная. Также можно подключить OpenAI-совместимый сервер. Подробнее — в [инструкции по установке локального ИИ](docs/LOCAL-AI-INSTALLATION.md).
